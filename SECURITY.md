# Security Policy

## Supported Versions

All versions of **mimosa** are currently supported and receive security fixes.

| Version | Supported          |
| ------- | ------------------ |
| All     | :white_check_mark: |

## Reporting a Vulnerability

We take the security of this project seriously. If you believe you have found a security vulnerability in **mimosa**, please report it to us privately before public disclosure.

### How to Contact Us

Do **not** open a public issue on GitHub for security vulnerabilities.

Please report vulnerabilities by emailing:
📧 **solanosalex@gmail.com**

To help us process and resolve the issue quickly, please include:

- **Description:** A description of the vulnerability and its potential impact.
- **Reproduction Steps:** Detailed steps to reproduce the issue (including PoC code, CLI commands, or payloads where applicable).
- **Environment:** OS, environment details, or specific configuration settings.
- **Mitigation:** Any suggested fixes or temporary workarounds (if known).

### What to Expect

- **Acknowledgment:** We will acknowledge receipt of your report within **48 hours**.
- **Investigation:** We will investigate the reported issue and provide updates on our progress.
- **Resolution & Disclosure:** Once a fix is released, we will coordinate public disclosure and provide credit (unless you prefer to remain anonymous).
